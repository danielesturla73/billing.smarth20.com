Prese e distretti{% if comune %} — {{ comune }}{% endif %}

Neta H2O associa i distretti alle prese: qui ci sono quelle con distretto NO DISTRETTO, * (non indicato) o di un altro comune non associabile, da sistemare guardando la mappa. Il distretto proposto viene dalla posizione: quello in cui la presa cade, oppure il più vicino entro {{ distanza_max }} m. Se la via è nello stradario prevale la via (prima l'indirizzo, poi la posizione). Le conferme finiscono nel file Excel per Neta e non cambiano i volumi: il distretto giusto entra nei calcoli quando Neta corregge il suo gestionale e arriva l'estrazione successiva. Coordinate e distretto sono quelli dell'estrazione più recente di ogni servizio.

Stradario via → distretto

{% if puo_modificare %} {% endif %}

Ricavato una tantum dalla posizione delle prese: il distretto di una via è quello in cui cade la maggior parte delle sue prese. Le vie divise tra due distretti hanno un tratto per distretto (per civico, a volte pari e dispari separati), contando un voto per civico; un palazzo con più prese tutte in un altro distretto diventa un'eccezione della via, da verificare. Le vie senza un taglio netto restano a cavallo e non si controllano. Le prese la cui via è di un altro distretto finiscono nell'elenco con il motivo Via di altro distretto. Il file è project_docs/stradario_distretti.csv, correggibile a mano; rigenerarlo cancella le correzioni fatte per questo comune. L'ultima colonna viene da OpenStreetMap (© OpenStreetMap contributors, ODbL), indipendente dalle coordinate di Neta: i distretti che il tracciato della via attraversa, in proporzione alla lunghezza; in rosso se non c'è il distretto dello stradario.
